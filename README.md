# Guardrail Options

Guardrail Options is a Nifty and Bank Nifty options-buying prop trading simulator. It provides the foundation for simulated trading, account risk controls, live market data, and trade journaling, with Firebase Authentication for user identity.

## Tech stack

- Node.js and Express
- Socket.io
- MongoDB and Mongoose
- Firebase Authentication
- React and Vite
- Tailwind CSS
- TradingView Lightweight Charts
